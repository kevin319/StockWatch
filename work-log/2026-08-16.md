# 2026-08-16 工作紀錄

## 概要

本次 session 涵蓋 StockWatch 前端 UI 修正、股價走勢圖功能開發、以及設定頁擴充。

---

## 1. iPhone 安全區域頂部間距修正

**問題：** 頂部 padding 硬編碼 54px，在不同裝置留白不一致。

**改法：**
- `styles.css`：新增 `--safe-top: env(safe-area-inset-top, 0px)` CSS 變數
- 四處硬編碼 `54px` 改為 `calc(var(--safe-top) + 10px)`
- `.hero-card` margin 從 `96px` 改為 `calc(var(--safe-top) + 52px)`
- `index.html` / `login.html`：viewport meta 加上 `viewport-fit=cover`

## 2. 搜尋列點擊區域加大

**改法：** `.search-field` padding 從 `8px 12px` 加大到 `12px 14px`

## 3. Hero card 淺色主題修正

**問題：** 淺色 theme 下市場時間卡片仍顯示深色。

**改法：** Hero card 預設改為淺色配色，`[data-theme="dark"]` 下才套深色。子元素顏色從硬編碼 `rgba(255,255,255,...)` 改為 `var(--text-*)` 變數。

## 4. 股價走勢圖功能（主要開發）

**需求：** 在股票展開面板加入完整走勢圖，模仿參考 App 截圖。

### 後端 — `app/api/stock.py`
- 新增 `GET /history/{ticker}?range=X` 端點，需登入驗證
- `_RANGE_MAP`：將 range 字串對應 yfinance 的 (period, interval)
- `_compute_history()`：純 Python 計算 OHLCV + MA20/60/120（sliding window）+ MDD（running peak）
- `history_cache`：30 分鐘快取
- 修正：`hist.dropna(subset=["Close"])` 處理 yfinance NaN、`math.isnan()` 檢查 volume

### 前端 — `static/main.js`
- **圖表渲染 `renderChart()`**：Canvas 2D 繪製
  - 面積圖 + 漸層填充 + 收盤價折線
  - MA20（藍）/ MA60（橘）/ MA120（紫）均線
  - 成交量柱狀圖（紅漲綠跌）
  - 均價虛線
- **四角覆蓋標注**：HTML absolute 定位，顯示最高/最低/均價/漲跌百分比
- **時間區間切換**：24H / 5D / 1M / 3M / 1Y / 5Y / Max，`switchChartRange()` + `loadChartIfNeeded()`
- **MDD 顯示**：底部 footer 顯示最大回撤
- **Hover 十字線系統**：
  - `_bindChartHover()`：mousemove/mouseleave/touchmove/touchend 事件
  - `_drawCrosshair()`：overlay canvas 繪製藍色虛線 + 價格圓點
  - `_updateHoverInfo()`：顯示日期、價格、漲跌、漲跌%、均價、成交量；同步更新 MA legend
  - `_hideHoverInfo()`：隱藏 hover 資訊，恢復 MA legend 到最新值
  - guard 改掛在 DOM element `wrap._hoverBound`，避免換股失效

### 前端 — `static/styles.css`
- 新增 chart 相關樣式：`.chart-section`、`.chart-canvas-wrap`、`.chart-overlay`、`.chart-range-bar`、`.chart-mdd`、`.chart-skeleton`
- MA legend：`.chart-ma-legend`、`.chart-ma-dot-20/60/120`
- Hover info：`.chart-hover-info` + `.hover-idle`（`visibility: hidden; opacity: 0`）

## 6. Bug 修正

| 問題 | 根因 | 修法 |
|------|------|------|
| Hover 換股失效 | `_chartHoverBound` 全域物件保留過期 entry | 改用 DOM element property `wrap._hoverBound` |
| Hover 時圖表高度跳動 | `.hidden` class 用 `display: none` 造成 reflow | 改用 `.hover-idle`（`visibility:hidden; opacity:0`）+ `min-height: 17px` |
| MA legend hover 時高度跳動 | hover 到無 MA 值的資料點時項目被移除 | 新增 `_maLegendHtml()` 永遠輸出三個 MA 項目，無值顯示「—」；`.chart-ma-legend` 加 `min-height: 11px` |
| `safeId` 使用前未宣告 | `hoverHtml` 引用 `safeId` 在宣告之前 | 將 `var safeId = ...` 移到 hover HTML 之前 |
| yfinance NaN 資料 | Close 欄含 NaN 導致 MA 計算錯誤 | `hist.dropna(subset=["Close"])` + `math.isnan()` 檢查 |
